# civita-parameter-identification

Part of CIVITA, the Computational Infrastructure for Validation, Integration, Testing, and Assessment.

Scientific tools and workflows for identifying computational model parameters from experimental evidence.

This component is under development. The planned scope includes support for multiple computational models and transparent, reproducible calibration procedures.

- [CIVITA website](https://civita.network)
- [CIVITA community discussions](https://github.com/civita-network/civita/discussions)
